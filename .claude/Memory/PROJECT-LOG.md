# eidos-ds — Project Log (compiled)

Last updated: 2026-05-26 (Next.js 14 → 16 + React 18 → 19 upgrade; Turbopack now default).

## What this project is

Two things in one repo:
1. **The Eidos Design System app** — the multi-page DS documentation site (Introduction,
   foundations, ~80 components, charts, elements, AI surfaces, patterns, IDP example
   screens), running as a **Next.js (App Router)** app.
2. **The engineering harness** in **`.claude/`** — subagents, skills, commands, hooks,
   settings, plus the design-systems/craft knowledge — so professional, structured UI work
   can be done from Claude Code in the terminal (originally done in the Open Design app).

Eidos = the DS that powers Equifax/Boa Vista's Internal Developer Platform. Single accent
**ember `#FF6B35`** (≤2×/screen), **Geist Sans/Mono**, warm-OKLCH palette, RTL first-class.

Run: `npm install && npm run dev` → <http://localhost:3000> (Introduction).

## Timeline of work (what & why)

### 1. Harness extraction (from the Open Design app)
- Source: `/Applications/Open Design.app/.../open-design/` (skills, design-systems, craft,
  frames, prompt-templates) + the project data for the original `eidos-design-system`.
- Built `.claude/` as the executable harness; everything translated to English.

### 2. DS site → Next.js (pragmatic port)
- The original DS was browser-Babel: IIFE page modules registering `window.PAGES['<slug>']`
  (examples `window.EXAMPLES`), shared components on `window`, loaded by in-page Babel.
- Ported to Next.js via a **registry bridge**: `install-globals` puts react/react-dom/
  recharts on `window`; `src/ds/core/index.ts` loads core modules; `scripts/gen-manifest.mjs`
  turns `nav-config.js` into an import manifest; a client loader renders the page module.
- Compiles with **`next/babel`** (`.babelrc`) because the legacy JSX is looser than SWC.
- Renders client-side (SSR shows a brief splash).

### 3. Full merge of `Eidos-DS.zip` (the modern DS — color system v1.2)
- The zip used the SAME architecture, modern version (warm **OKLCH** palette, elevation
  scale `--elev-*`, 7 surface tiers; ember unchanged). Adopted wholesale:
  replaced `src/styles/{tokens,ds,example-shell}.css` + the 8 core modules + pages/examples.
- **Preserved only ours-not-in-zip**: `get-started/llm` page + AI-chat example screens
  (`ai-chat-empty/-thread/ai-projects/ai-project-detail`) + `ai-shell`. nav-config got those
  injected back.

### 4. Harness curation (strict scope)
- Decision: the harness contains ONLY what serves **DS / Harness-Eng / DevEx Platform /
  IDP**. Removed (deleted, not archived): decks/PPT, posters, social, video, marketing
  landings, blogs, consumer mobile, business docs; the 139 inspiration brands (kept only
  `forge`); prompt-templates; device frames.
- The 7 kept OD skills (dashboard, docs-page, critique, tweaks, etc.) were rewritten to be
  Eidos-native (no `$imagegen`/`<artifact>`/OD CLI).

### 5. Harness consolidated into `.claude/`
- Everything moved from a separate `harness/` folder into `.claude/` (skills, design-systems,
  craft). 8 subagents, ~21 skills, 4 commands, hooks, settings, plugin scaffold.
- See `.claude/README.md` + `docs/HARNESS-GAP-ANALYSIS.md`.

### 6. React/Next.js re-architecture (gap analysis → phased migration)
Gap analysis: `docs/REACT-NEXTJS-GAP-ANALYSIS.md`. Decisions: Tailwind v4 (later trimmed —
see below), TSX, **incremental (strangler)**, examples at a separate `/example/` route.

**The hard rule (learned the hard way):** NEVER reinvent the approved visual. Reuse the
original `ds.css`/tokens + the original components; new pages copy the JSX body **verbatim**
and only swap the wrapper/imports. (A first attempt that re-styled pages in fresh Tailwind
was rejected and reverted.)

## Conventions / how to work
- **Verify with**: `npm run build` (157 routes, SWC, must be green) + `npm run verify`
  (headless render check; needs Chrome via `CHROME_PATH`). Probe scripts must live in the
  repo (so `ws` resolves), not `/tmp`. Note: `verify-render.mjs` only reports
  `exceptionThrown` — React render errors surface as console errors, so a thorough sweep
  must also watch `Runtime.consoleAPICalled` (type `error`) + a body-length floor.
- **Add/migrate a page**: edit `nav-config.js`, then add `src/ds/migrated/<slug>.tsx`:
  `'use client'`, `import { … } from '@/ds/core'` (+ `import * as React` if it uses
  `React.`), `export default function`. slug = the route key (charts→`chart-*`,
  elements→`el-*`, ai→`ai-*`, patterns→`pat-*`, get-started/components→`components-catalog`,
  home→`overview`). Keep JSX SWC-valid (escape literal `>` as `{'>'}`). gen scripts auto-run.
- **Kill stray `next dev` on :3000 before `rm -rf .next && build`** — a zombie server
  corrupts `.next` ("Cannot find module ./XXXX.js").
